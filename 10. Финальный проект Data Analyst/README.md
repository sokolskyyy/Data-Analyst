# Проект: Финальный проект Data Analyst

## Описание
Финальный проект состоит из двух частей. Первая часть посвящена анализу данных сервиса «Яндекс Афиша» с помощью SQL и созданию интерактивного дашборда в Yandex DataLens для отслеживания динамики ключевых бизнес-показателей. Вторая часть — исследовательский анализ данных в Python и проверка статистических гипотез о различиях в поведении пользователей мобильных и стационарных устройств.

---

## Задачи проекта
1. **Часть 1. Анализ данных с помощью SQL и создание дашборда в DataLens:**
   - Первичное знакомство с данными (подключение к БД PostgreSQL, изучение структуры таблиц).
   - Проверка качества и корректности данных (уникальность идентификаторов, пропуски, аномалии в выручке, разные валюты).
   - Расчет ключевых бизнес-метрик (итоговая выручка, количество заказов, средняя выручка с заказа, число уникальных покупателей).
   - Создание визуализаций в DataLens (линейные графики недельной динамики, структура выручки по типам устройств и мероприятий, топ-сегменты).
   - Сборка итогового дашборда «Финальный проект» с фильтрацией по валюте, дате, типу событий и региону.
2. **Часть 2. Исследовательский анализ данных в Python и проверка гипотез:**
   - Загрузка и предобработка данных (удаление пропусков и явных/неявных дубликатов, фильтрация выбросов по 99-му процентилю).
   - Конвертация валют (перевод тенге в рубли) и создание новых признаков (выручка за 1 билет, месяц, сезон).
   - Исследовательский анализ сезонной динамики (сравнение спроса и средней стоимости билетов летом и осенью).
   - Анализ осенней активности пользователей (недельная цикличность, DAU, средний чек в будни и выходные).
   - Выявление топ-регионов и топ-партнёров по объёму выручки и количеству заказов.
   - Статистическая проверка гипотез (тест Манна-Уитни):
     - Гипотеза 1: Мобильные пользователи совершают больше заказов, чем пользователи ПК.
     - Гипотеза 2: Время между заказами у мобильных пользователей выше, чем у пользователей ПК.
3. **Формулирование итоговых выводов и рекомендаций для продуктовой команды.**

## Технологии
- **SQL (PostgreSQL)** — написание аналитических запросов и извлечение данных.
- **Yandex DataLens** — платформа для визуализации данных и создания интерактивных дашбордов.
- **Python** — основной язык для исследовательского анализа и проверки гипотез.
- **Pandas** — обработка и анализ данных.
- **Matplotlib / Seaborn** — визуализация распределений и динамики.
- **SciPy (stats) / Statsmodels** — статистическое тестирование (тест Манна-Уитни).
- **Jupyter Notebook** — среда разработки.
