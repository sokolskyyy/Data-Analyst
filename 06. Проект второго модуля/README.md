# Проект: Исследование стартапов

## Описание
Исследование закономерностей финансирования стартапов для венчурной компании. Анализ динамики и структуры финансирования, выявление перспективных сегментов рынка и типов инвестиций для формирования инвестиционной стратегии.

---

## Задачи проекта
1. Загрузка и предобработка данных
2. Инжиниринг признаков:
   - Группы по срокам финансирования
   - Выделение средних и нишевых сегментов рынка
3. Работа с выбросами и анализ:
   - Выявление аномальных значений в каждом сегменте
   - Определение границ рассматриваемого периода
   - Анализ типов финансирования по объёму и популярности
4. Анализ динамики:
   - Динамика предоставления финансирования по годам
   - Динамика финансирования по массовым сегментам
   - Годовая динамика доли возвращённых средств
5. Формулирование итоговых выводов и рекомендаций

---

## Технологии
- **Python** — основной язык программирования
- **Pandas** — обработка и анализ данных
- **NumPy** — численные вычисления
- **Matplotlib** — визуализация данных
- **Seaborn** — статистическая визуализация
- **Missingno** — визуализация пропусков
- **Jupyter Notebook** — среда разработки
