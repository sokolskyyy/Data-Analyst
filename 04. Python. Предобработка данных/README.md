# Проект: Рынок видеоигр

## Описание
Анализ развития игровой индустрии с 2000 по 2013 год для подготовки статьи о развитии индустрии игр. Исследование игровых платформ, объёмов продаж игр разных жанров и региональных предпочтений игроков. Акцент на играх жанра RPG.

---

## Задачи проекта
1. Загрузка и знакомство с данными
2. Проверка ошибок в данных и их предобработка:
   - Приведение названий столбцов к snake_case
   - Преобразование типов данных
   - Обработка пропусков
   - Удаление дубликатов (явных и неявных)
3. Фильтрация данных за период 2000–2013 годы
4. Категоризация данных:
   - Категоризация оценок пользователей (высокая, средняя, низкая)
   - Категоризация оценок критиков (высокая, средняя, низкая)
   - Выделение топ-7 платформ по количеству игр

---

## Технологии
- **Python** — основной язык программирования
- **Pandas** — обработка и предобработка данных
- **NumPy** — численные вычисления
