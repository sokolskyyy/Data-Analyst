# Проект: Расчёт и визуализация бизнес-метрик и показателей

## Описание
Сервису доставки еды «Всё.из.кафе» требуется анализ ключевых бизнес-метрик. Необходимо подготовить данные, создать дашборд в DataLens для визуализации состояния клиентской базы в городе Саранске за май-июнь 2021 года и составить аналитический отчёт с выводами.

---

## Задачи проекта
1. Подготовка SQL-запросов к базе данных и интеграция с DataLens
2. Расчёт ключевых метрик:
   - **DAU** (количество активных пользователей за день)
   - **Conversion Rate** (коэффициент конверсии)
   - **Средний чек** (средняя сумма покупки)
   - **LTV** (совокупная ценность клиента за период)
   - **Retention Rate** (коэффициент удержания пользователей)
3. Создание визуализаций:
   - Построение линейных графиков для отслеживания динамики DAU, конверсии и среднего чека
   - Построение столбчатых диаграмм и таблиц для анализа LTV и удержания (Retention)
4. Сборка итогового дашборда «Ключевые бизнес-метрики в Саранске (май — июнь 2021)»
5. Написание аналитической записки с выводами по каждой метрике (DAU, конверсия, средний чек, Retention) за период с начала мая до конца июня

## Технологии
- **SQL** — написание аналитических запросов для агрегации метрик
- **Yandex DataLens** — платформа для визуализации данных и создания интерактивных дашбордов
- **Анализ когорт (Cohort Analysis)** — методология для расчёта коэффициента удержания (Retention Rate)
- **Jupyter Notebook / Python** — первичная проверка данных и подготовка выводов (по необходимости)
