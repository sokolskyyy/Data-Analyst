# Проект: TED-конференции

## Описание
Разработка дашборда для компании по организации конференций TED. Анализ опыта проведённых конференций для планирования нового мероприятия.

---

## Ссылка на дашборд
**[Дашборд TED-конференции](https://datalens.yandex/wzgddcx1q8zkg)**

---

## Задачи дашборда
1. Определить популярные темы и реакцию зрителей
2. Рассчитать среднее количество выступающих на конференции
3. Найти оптимальную длительность выступлений
4. Выявить самых интересных выступающих

---

## Структура дашборда

### Верхнеуровневые показатели
- Количество конференций
- Количество выступлений
- Уникальное количество выступающих
- Количество тем/тегов

### Детализация по конференциям
- Страна → конференция
- Средняя длительность выступления
- Максимальное количество просмотров
- Количество аплодисментов
- Количество выступающих

### Исследование выступлений
- Топ-10 самых смешных выступлений
- Топ-20 самых популярных тегов

### Информация о выступающих
- Род деятельности выступающих с наибольшим количеством аплодисментов

### Детальная таблица
- Полная информация о каждом выступлении

---

## Фильтры
- Страна выступления
- Название конференции
- Тег выступления
- Дата записи

---

## Технологии
- **Yandex DataLens** — создание дашборда
- **SQL (PostgreSQL)** — подготовка данных
