# Проект: TED-конференции 
 
## Описание 
Разработка дашборда для компании по организации конференций TED. 
 
## Ссылка на дашборд 
**[Дашборд TED-конференции](https://datalens.yandex/wzgddcx1q8zkg)** 
 
## Задачи 
1. Определить популярные темы и реакцию зрителей 
2. Рассчитать среднее количество выступающих на конференции 
3. Найти оптимальную длительность выступлений 
4. Выявить самых интересных выступающих 
 
## Технологии 
- **Yandex DataLens** 
- **SQL (PostgreSQL)**
