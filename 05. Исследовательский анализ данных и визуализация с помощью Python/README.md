# Проект: Исследовательский анализ данных рынка общественного питания Москвы

## Описание
Исследовательский анализ данных (EDA) рынка общественного питания Москвы для инвесторов, планирующих открытие нового заведения. Анализ категорий, районов, сетевых/несетевых заведений, посадочных мест, рейтингов, ценовых категорий и среднего чека.

---

## Задачи проекта
1. Загрузка и знакомство с данными
2. Предобработка данных:
   - Преобразование типов данных
   - Обработка пропусков
   - Удаление дубликатов
   - Создание новых столбцов (is_24_7, hours_missing)
3. Исследовательский анализ данных:
   - Анализ категорий заведений
   - Анализ административных районов Москвы
   - Соотношение сетевых и несетевых заведений
   - Анализ посадочных мест
   - Анализ рейтингов
   - Корреляционный анализ
   - Топ-15 популярных сетей
   - Анализ среднего чека по районам
4. Формулирование выводов и рекомендаций

---

## Технологии
- **Python** — основной язык программирования
- **Pandas** — обработка и анализ данных
- **NumPy** — численные вычисления
- **Matplotlib** — базовая визуализация
- **Seaborn** — статистическая визуализация
- **Phik** — расчет коэффициента корреляции phi_k
- **Jupyter Notebook** — среда разработки
