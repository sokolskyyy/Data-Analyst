# Проект: Секреты Тёмнолесья

## ?? Описание проекта
Анализ внутриигровых покупок в игровой вселенной "Секреты Тёмнолесья". Исследование влияния характеристик игроков и их игровых персонажей на покупку внутриигровой валюты **«райские лепестки»**, а также оценка активности игроков при совершении внутриигровых покупок.

---

## ?? Цель исследования
1. Изучить влияние характеристик игроков и их игровых персонажей на покупку внутриигровой валюты
2. Оценить активность игроков при совершении внутриигровых покупок
3. Определить долю платящих игроков

---
