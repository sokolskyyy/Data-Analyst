# Проект: Расчёт метрик в SQL и проверка гипотез в Python

## Описание
Проект состоит из двух частей. В первой части на данных сервиса «Яндекс Книги» проводится проверка гипотезы о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг по сравнению с пользователями из Москвы. Во второй части анализируются результаты A/B-тестирования новой версии сайта интернет-магазина BitMotion Kit.

---

## Задачи проекта
1. **Подготовка данных в SQL (Яндекс Книги):**
   - Подготовка и агрегация данных о пользователях из Москвы и Санкт-Петербурга.
2. **Проверка гипотезы в Python:**
   - Загрузка и очистка данных (удаление дубликатов по `puid`).
   - Сравнение размеров групп и описательных статистик (среднее, медиана, std).
   - Визуализация распределений с помощью `boxplot`.
   - Формулировка нулевой и альтернативной гипотез о разнице во времени активности.
   - Проведение одностороннего двухвыборочного t-теста (`ttest_ind`, alternative='greater').
   - Интерпретация p-value и финальный вывод.
3. **Анализ результатов A/B-тестирования (BitMotion Kit):**
   - Загрузка данных участников (`ab_test_participants`) и событий (`ab_test_events`).
   - Оценка корректности проведения теста (проверка соответствия ТЗ, равномерности распределения, исключение пересечений с конкурирующим тестом).
   - Определение горизонта анализа (события в течение первых 7 дней после регистрации).
   - Расчет конверсии зарегистрированных пользователей в покупателей для групп A и B.
   - Проверка статистической значимости изменения конверсии (Z-тест для пропорций).
4. **Подготовка аналитической записки:**
   - Формулирование выводов по гипотезе и результатам A/B-теста.

## Технологии
- **Python** — основной язык программирования
- **Pandas** — обработка и анализ данных
- **Matplotlib / Seaborn** — визуализация данных (ящики с усами, гистограммы)
- **SciPy (stats)** — проведение t-теста для независимых выборок
- **Statsmodels (proportions_ztest)** — проверка статистической значимости различий конверсии в A/B-тесте
- **Jupyter Notebook** — среда разработки
