🛠️ **Навыки**
- **SQL (PostgreSQL)** — извлечение и обработка данных, оконные функции, подзапросы, работа с датой и временем, решение ad hoc задач
- **Python** — синтаксис, функции, циклы, условные выражения, работа со словарями и множествами
- **Pandas** — предобработка данных, фильтрация, группировка, объединение датафреймов, работа с пропусками
- **Визуализация** — построение графиков в Python (Matplotlib, Seaborn), создание дашбордов в DataLens
- **Статистический анализ** — проверка гипотез, распределения, теория вероятностей, статистические тесты
- **A/B тестирование** — расчёт выборки, проверка результатов, тест Манна-Уитни, Z-тест пропорций
- **Бизнес-метрики** — расчёт и визуализация продуктовых метрик, воронка, LTV, когортный анализ
- **Google Таблицы** — предобработка, формулы, функции, презентация данных
- **Исследовательский анализ данных (EDA)** — описательная статистика, визуализация, сводные таблицы

📂 **Проекты**

**01. SQL. Анализ данных и решение ad hoc задач**
*Секреты Тёмнолесья*

Анализ внутриигровых покупок в игровой вселенной "Секреты Тёмнолесья". Исследование влияния характеристик игроков на покупку внутриигровой валюты.
*Технологии: SQL (PostgreSQL)*

**02. Визуализация данных с помощью DataLens. Создание дашбордов**
*Визуализация данных сервиса доставки еды*

Создание дашборда для отслеживания ключевых бизнес-метрик и анализа структуры выручки.
*Технологии: DataLens, SQL*

**03. Проект первого модуля**
*Анализ данных Афиши*

Исследование и подготовка данных сервиса Яндекс Афиша для последующей визуализации.
*Технологии: Python, Pandas, DataLens*

**04. Python. Предобработка данных**
*Предобработка данных для исследования стартапов*

Предобработка и очистка данных, работа с пропусками, дубликатами и типами данных для анализа венчурных инвестиций.
*Технологии: Python, Pandas*

**05. Исследовательский анализ данных и визуализация с помощью Python**
*Исследование стартапов*

Исследовательский анализ данных и визуализация закономерностей финансирования стартапов для венчурной компании.
*Технологии: Python, Pandas, Matplotlib, Seaborn*

**06. Проект второго модуля**
*Исследование стартапов*

Подготовка данных, инжиниринг признаков и анализ динамики финансирования.
*Технологии: Python, Pandas*

**07. Расчёт и визуализация бизнес-метрик и показателей**
*Расчёт и визуализация бизнес-метрик и показателей*

Расчёт ключевых бизнес-метрик для сервиса доставки еды и создание дашборда в DataLens для визуализации DAU, конверсии, среднего чека, LTV и Retention Rate.
*Технологии: DataLens, SQL*

**08. Анализ результатов A/B тестирования с помощью Python**
*Анализ результатов A/B тестирования*

Расчёт параметров A/B-теста, оценка корректности его проведения, мониторинг и анализ результатов с помощью Python.
*Технологии: Python, Pandas, SciPy, NumPy*

**09. Проект третьего модуля Data Analyst**
*Расчёт метрик в SQL и проверка гипотез в Python*

Расчёт метрик в SQL, проверка гипотезы о времени активности пользователей в сервисе «Яндекс Книги», а также анализ результатов A/B-теста интернет-магазина.
*Технологии: Python, Pandas, A/B тестирование, SciPy, Statsmodels*

**10. Финальный проект Data Analyst**
*Финальный проект Data Analyst*

Комплексный проект по созданию дашборда в DataLens на основе SQL-запросов и проведению исследовательского анализа данных в Python с проверкой статистических гипотез для сервиса Яндекс Афиша.
*Технологии: SQL (PostgreSQL), Python (Pandas, SciPy, Matplotlib), DataLens*
