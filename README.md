### 1. SQL. Анализ данных
**[Секреты Тёмнолесья](./проекты/01_SQL_Анализ_данных/(секреты_темнолесья).sql)**

Анализ внутриигровых покупок в игровой вселенной "Секреты Тёмнолесья". Исследование влияния характеристик игроков на покупку внутриигровой валюты.

**Задачи:**
- Определение доли платящих игроков
- Анализ покупок в разрезе расы персонажа
- Статистический анализ сумм покупок

**Технологии:** SQL (PostgreSQL)
