## 🛠️ Навыки

- **SQL (PostgreSQL)** — извлечение и обработка данных, оконные функции, подзапросы, работа с датой и временем, решение ad hoc задач
- **Python** — синтаксис, функции, циклы, условные выражения, работа со словарями и множествами
- **Pandas** — предобработка данных, фильтрация, группировка, объединение датафреймов, работа с пропусками
- **Визуализация** — построение графиков в Python (Matplotlib, Seaborn), создание дашбордов в DataLens
- **Статистический анализ** — проверка гипотез, распределения, теория вероятностей, статистические тесты
- **A/B тестирование** — расчёт выборки, проверка результатов, тест Манна-Уитни, Z-тест пропорций
- **Бизнес-метрики** — расчёт и визуализация продуктовых метрик, воронка, LTV, когортный анализ
- **Google Таблицы** — предобработка, формулы, функции, презентация данных
- **Исследовательский анализ данных (EDA)** — описательная статистика, визуализация, сводные таблицы
