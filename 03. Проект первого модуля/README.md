# Проект: Анализ данных для агентства недвижимости

## Описание
Анализ объявлений о продаже жилой недвижимости в Санкт-Петербурге и Ленинградской области для агентства недвижимости. Цель — найти самые перспективные сегменты недвижимости для выхода на новый рынок.

## Задачи проекта

### 1. Исследовательский анализ данных
- Определение временного интервала данных (2014-2019)
- Анализ распределения по типам населённых пунктов
- Изучение времени активности объявлений
- Расчёт доли снятых с публикации объявлений (86.55%)
- Анализ стоимости квадратного метра
- Выявление аномальных значений

### 2. Решение ad hoc задач (SQL)

**Задача 1. Время активности объявлений**
- Категоризация объявлений по длительности: low (1-30 дней), middle (31-90 дней), high (91-180 дней), very_high (181+ дней), non category
- Сравнение характеристик недвижимости в Санкт-Петербурге и Ленинградской области

**Задача 2. Сезонность объявлений**
- Анализ публикаций и снятий по месяцам
- Выявление сезонных тенденций
- Влияние сезона на стоимость и площадь

### 3. Доработка дашборда в DataLens
- Доработка существующего дашборда по ТЗ заказчика
- Добавление новых элементов и фильтров
