# Проект: Анализ результатов A/B тестирования с помощью Python

## Описание
Команда разработчиков рекомендательных систем развлекательного приложения создала новый алгоритм, который, по их мнению, будет показывать более интересный контент для каждого пользователя. Задача аналитика — рассчитать параметры A/B-теста для проверки гипотезы, оценить корректность его проведения и проанализировать результаты эксперимента, чтобы принять решение о внедрении нововведения.

---

## Задачи проекта
1. Работа с историческими данными (EDA):
   - Загрузка и первичное знакомство с данными (анализ пользователей и сессий).
   - Анализ динамики числа регистраций (DAU по зарегистрированным пользователям).
   - Анализ числа просмотренных страниц в первых сессиях.
   - Оценка доли пользователей, просмотревших более 4 страниц в первую сессию (прокси-метрика удовлетворённости контентом).
2. Подготовка к тесту:
   - Формулировка целевой метрики (доля успешных первых сессий).
   - Расчёт необходимого размера выборки (метод `solve_power()`).
   - Расчёт длительности A/B-теста исходя из текущего дневного трафика.
3. Мониторинг A/B-теста:
   - Проверка распределения пользователей по группам (процентная разница).
   - Проверка пересечений пользователей (независимость выборок).
   - Проверка равномерности распределения по типам устройств и регионам.
4. Проверка результатов A/B-теста:
   - Подсчёт основной метрики (доля успешных первых сессий с просмотром 4+ страниц).
   - Формулировка нулевой и альтернативной гипотез, определение барьерных и прокси-метрик.
   - Проверка статистической значимости различий между группами (Z-тест для долей).
5. Формулирование итоговых выводов и рекомендаций для команды разработки.

## Технологии
- **Python** — основной язык программирования
- **Pandas** — обработка и анализ данных
- **Matplotlib** — визуализация данных (линейные графики, столбчатые диаграммы, круговые диаграммы)
- **Statsmodels** — статистические тесты (расчёт мощности теста `NormalIndPower`, Z-тест для пропорций `proportions_ztest`)
- **Jupyter Notebook** — среда разработки
